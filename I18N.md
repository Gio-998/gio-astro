# Adding a locale (e.g. German, /de/)

URLs are `/<locale>/<localized slugs>/`. One map decides every localized slug: `src/lib/i18n-routes.ts`.
Links, the language switch, `<link rel="alternate" hreflang>`, canonicals and `sitemap.xml` all go through
`localizedPath(locale, internalPath)` / `routeAlternates(internalPath)`, so a new locale needs no SEO special cases.

Internal paths use the English folder names: `/pricing/`, `/horoscope/<sign>/<date>/`, `/how-it-works/` …

## Steps for /de/
1. **Content**: add `src/content/de/*` (copy `en`), register `de` in `LOCALES` (src/content/index.ts) and
   `LOCALE_META` (src/lib/seo.ts: `{ hreflang: "de", og: "de_DE", name: "Deutsch" }`).
2. **Route map**: add `"de"` to `ROUTE_LOCALES` and give it slugs in `src/lib/i18n-routes.ts`:
   ```ts
   pricing:   { en: "pricing",   mk: "ceni",            de: "preise" },
   horoscope: { en: "horoscope", mk: "dneven-horoskop", de: "tageshoroskop" },
   SIGN_SLUGS.de = { aries: "widder", taurus: "stier", gemini: "zwillinge", cancer: "krebs", leo: "loewe", virgo: "jungfrau",
                     libra: "waage", scorpio: "skorpion", sagittarius: "schuetze", capricorn: "steinbock", aquarius: "wassermann", pisces: "fische" }
   ```
   Sections not listed keep the internal slug (e.g. `/de/blog/`). To localize one (e.g. `/de/so-funktioniert-es/`),
   add a row: `"how-it-works": { de: "so-funktioniert-es" }`.
3. **Route folders** (static export has no middleware, so each localized slug needs a folder under `src/app/[lang]/`):
   for a new slug create a thin folder that re-uses the shared page, like `ceni/page.tsx` does for pricing
   (`<PricingRoute lang={lang} owner="de" />`) and `dneven-horoskop/` does for the horoscope (`signParams(lang, "de")`).
   Add the horoscope bank `src/content/horoscope/de.ts` (its `slug`/`signSlug` come from `HORO_SLUGS.de`) and `de` to `HORO_LOCALES`.
4. **Redirects**: `vercel.json` 308s a locale's URL that uses another locale's slug (e.g. `/de/pricing/` → `/de/preise/`).
   `tests/i18n-routes.test.ts` lists every needed rule from the map and fails until vercel.json has it; add the rules
   before `{ "handle": "filesystem" }`, plus the dated-horoscope rule after it (`/de/tageshoroskop/<slug>/<date>/` → sign page).
5. **Share images**: add the locale's names to `scripts/og-names.json` and run `python3 scripts/build-og-defaults.py scripts/og-names.json`.
6. **Browser text**: copy `src/lib/shell/de.tsx` and `mid-de.ts` for the locale and add it to `PROVIDERS` in `src/lib/shell/index.tsx`.
   Without this the locale works, but its reading pages load the full text of every language (see `src/lib/content-lazy.ts`).
7. Run `npm run check:copy && npx tsc --noEmit && npm test && npm run build`, then check `/sitemap.xml` (an index) lists `/sitemap-de-*.xml` with hreflang inside.

## Rules
- Never change an existing EN/MK URL. If a slug must change, keep the old one as a 308 in vercel.json.
- One domain, subfolders (`/de/`), hreflang per language (`de`; add `de-AT`/`de-CH` only with different content), `x-default` = English.
- Translate titles, descriptions, OG images and schema `inLanguage`; slugs help a little, content and titles matter most.
